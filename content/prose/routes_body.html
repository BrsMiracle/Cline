🗺️ 方案 A · 7 天 · 新加坡进 → 吉隆坡出

D1抵达新加坡

落地樟宜 → 滨海湾夜景

  • 樟宜机场先别急着走，星耀樟宜（Jewel）的雨漩涡就在 T1 旁边，落地后顺路逛 1 小时。
  • 坐 MRT 或打车进市区，住 滨海湾 / 武吉士 / 牛车水一带（换乘最方便）。
  • 傍晚：鱼尾狮公园 → 滨海湾步道 → 金沙外围，19:45 / 20:45 到滨海湾花园看擎天树灯光秀（免费）。
D2新加坡

滨海湾花园＋金沙观景台

  • 上午：花穹＋云雾林（建议一开馆就进，人最少）。
  • 下午：艺术科学博物馆 或 国家美术馆（雨天备选）。
  • 傍晚：滨海湾金沙空中花园观景台看日落与亮灯（需提前订时段票）。
D3新加坡

圣淘沙一天（环球影城或海滩）

  • 环球影城：务必买指定日期票、按开园时间进场，先刷变形金刚与木乃伊。
  • 不玩乐园的话：圣淘沙缆车＋斜坡滑车＋海滩，晚上看时光之翼水舞秀。
  • 晚上回市区：克拉码头或老巴刹沙嗲街吃宵夜。
D4新加坡→马六甲

跨境巴士进马六甲（约 4–5 小时）

  • 上午从 黄金坊 Golden Mile 或 Beach Road 一带上车，坐 707 Inc / KKKL / Delima 等直达马六甲。
  • 下午到马六甲，住鸡场街（Jonker Street）周边，步行就能逛完老城。
  • 傍晚：荷兰红屋广场 → 圣保罗堂 → 马六甲河畔，晚上逛鸡场街夜市（仅周五至周日）。
D5马六甲→吉隆坡

上午老城，下午巴士去吉隆坡

  • 上午：峇峇娘惹祖屋博物馆 → 青云亭 → A Famosa；有车的话去海峡清真寺拍照。
  • 午后：Melaka Sentral 坐巴士到 KL TBS（约 2–2.5 小时，RM 10–15）。
  • 晚上：住 Bukit Bintang，直接去亚罗街夜市吃烤鸡翅与沙嗲。
D6吉隆坡

黑风洞＋市区经典线

  • 清晨：KTM Komuter 从 KL Sentral 到 黑风洞（往返 RM5.20），爬 272 级彩虹阶梯。
  • 中午回市区：独立广场 → 苏丹阿都沙末大厦 → 占美清真寺 → 中央艺术坊 → 茨厂街。
  • 傍晚：KLCC 公园拍双子塔，晚上 KL Tower 或双子塔观景台看夜景。
D7返程

吉隆坡 → 深圳 / 广州 / 香港

  • 白天航班：亚航 AK 06:05→10:20（KUL→SZX）、16:20→20:45，或峇迪 OD 10:10→14:10（KUL→HKG）。
  • 如果买了红眼 AK128（22:00→02:15+1），白天还能多玩半天，但落地深圳要提前安排接机。

🗺️ 方案 B · 6 天精简版 · 马来西亚进 → 新加坡出

D1抵达吉隆坡

广州/香港飞吉隆坡 → 双子塔夜景

  • 落地 KLIA / KLIA2，坐 KLIA Ekspres 到 KL Sentral 约 28 分钟。
  • 住 Bukit Bintang；晚上 KLCC 公园看喷泉与双子塔。
D2吉隆坡

黑风洞＋老城半日

  • 清晨黑风洞，午后独立广场—占美清真寺—茨厂街，晚上亚罗街。
D3吉隆坡→马六甲

上午巴士到马六甲

  • KL TBS → Melaka Sentral（2–2.5 小时）；下午红屋—圣保罗堂—马六甲河，晚上鸡场街（若逢周五六日）。
D4马六甲→新加坡

跨境巴士进新加坡

  • 上午娘惹祖屋博物馆，午后巴士到新加坡（约 4–5 小时，含过关）；晚上克拉码头。
D5新加坡

滨海湾＋圣淘沙

  • 上午花穹＋云雾林，下午金沙观景台或圣淘沙，晚上擎天树灯光秀。
D6返程

新加坡 → 深圳 / 广州 / 香港

  • 白天班次可选酷航 TR982（16:00→20:35，SIN→HKG）或新航/深航直飞深圳；避免 21:00→01:25 的南航红眼。

🗺️ 方案 C · 9–10 天加长版 · 加槟城

D1–D3新加坡

滨海湾＋圣淘沙＋牛车水／小印度／甘榜格南

  • 把 D3 拆成「圣淘沙半天＋文化街区半天」，牛车水、小印度、哈芝巷各留 1–2 小时。
D4–D5马六甲

新加坡跨境巴士进马六甲，住 1 晚

  • 马六甲值得住一晚而不是当天往返：夜市、河畔夜景和清晨的老城完全是两种感觉。
D6–D7吉隆坡

黑风洞、双子塔、独立广场、亚罗街

  • 第二天可加半日游：布城粉红清真寺或云顶高原。
D8–D9槟城

吉隆坡 → 槟城（ETS 火车或飞机）

  • 乔治市世界遗产区步行一天：壁画、姓氏桥、侨生博物馆、爱情巷；晚上新关仔角吃小吃。
  • 第二天：升旗山看全景＋极乐寺，下午回市区吃叻沙与煎蕊。
D10返程

槟城 → 吉隆坡 → 珠三角（联程）

  • 槟城直飞珠三角班次有限，通常走「槟城→KUL→深圳/广州/香港」联程，或从槟城飞回吉隆坡后接方案 A 的回程。
