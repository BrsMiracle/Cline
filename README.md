## lumen65 — LUMEN 65 交互式机械键盘产品页

- 项目源码与文档：[`lumen65/README.md`](lumen65/README.md)
- 单文件交付版（双击即可打开，无需服务器）：[`lumen65/lumen-65.html`](lumen65/lumen-65.html)

快速开始：

```bash
cd lumen65
npm install
npm run dev        # http://localhost:5173
npm run build      # 生产构建
npm run build:single   # 重新生成 lumen-65.html 单文件版
```
