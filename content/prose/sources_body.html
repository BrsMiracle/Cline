二、景点评分与票价来源

所有景点卡片上的「★ 评分 / 点评数 / 参考票价 / 开放时间 / 地址」均抓取自携程（Ctrip / you.ctrip.com）景点页的 2026-10-11 快照，包括新加坡、吉隆坡、马六甲、槟城四个城市的景点列表与详情页。其中：

  • 评分与点评数为携程用户评分（满分 5 分），点评数即该页显示的总点评量。
  • 「携程参考 ¥xx 起」是携程页面的人民币最低报价，不等于官方门市价，会随票种与日期浮动。
  • 能查到官方价的，正文里已单独标注，例如：新加坡环球影城官方门票 SGD 76 起（rwsentosa.com）、黑风洞 Temple Cave 免费 / Dark Cave RM35 / Ramayana Cave RM5 / Cave Villa RM7（持 MyKad）或 RM15（visitselangor.com）。
  • 开放时间为携程页面标注的营业时间，节假日与特殊日期可能调整，出行前请以官网为准。

五、免责声明与已知局限

请务必注意以下几点：
  • 机票价格是快照，不是实时。所有价格抓取于 2026-10-11，机票价格随时变动，下单前请以订票平台显示的最终价格为准。
  • 不同平台币种不同，未做换算。US$ / HK$ / SGD / MYR / CNY 混用是刻意的，因为强行换算会掩盖真实价差；比较时请按币种本身看。
  • 航班号不完整。Trip.com、Skyscanner 的报价页大多不显示航班号，本页航班号来自 FlightsFrom 航线清单与 Trip.com 时刻表区块，仅供识别，出票请以实际页面为准。
  • 部分行李额度未查到。南航、深航、国泰、马航、峇迪的官网行李计算器是交互式的，静态抓取不到具体公斤数，表中标为「未查到」而不是猜测。
  • 非机票类价格为参考区间。餐饮、住宿、市内交通、巴士票价等为公开资料与平台页面的参考区间，会随季节和商家调整。
  • 政策以官方为准。免签停留天数、入境卡要求、开放时间等均可能变动，出发前请到官方渠道再确认一次。
