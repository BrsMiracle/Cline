## 3. 交叉验证

- **槟城 → 香港**：AirAsia MOVE 报 MYR 359（11/13），Trip.com 报 HK$692（11/13）。按当日汇率 MYR 359 ≈ HK$691，两源一致。
- **深圳 → 槟城（11 月直飞）**：AirAsia MOVE 报 CNY 1,527，Trip.com 报 HK$872 起（≈ CNY 745），**相差近 ¥570**。此航线必须跨平台比价，不要只看一个平台。
- Trip.com 补充：SZX→PEN 每周 7 班直飞；PEN→HKG 每周 35 班；深圳→槟城 11 月单程均价 HK$1,239；槟城→香港 11 月单程均价 HK$589。
- Trip.com 直飞最低（SZX→PEN）示例：SZX 08:15→PEN 12:00（10/20，深航）；SZX 08:25→PEN 12:25（11/9，深航）。
- 中转方案（亚航经 KUL）：SZX 03:15→KUL→PEN 11:40（8h25m）；往返最低 HK$1,820（11/7–11/12）。

## 4. 结论

| 方案 | 机票总价（每人，人民币折算） |
|---|---|
| 不装槟城（深圳→新加坡 / 吉隆坡→深圳） | ≈ ¥786 + ¥571 = **¥1,357** |
| **槟城当出口**（深圳→新加坡 … 吉隆坡→槟城→香港） | ≈ ¥786 + ¥591 = **¥1,377** ⭐ |
| 槟城当入口（香港→槟城 … 新加坡→广州） | ≈ ¥764 + ¥898 = **¥1,662** |
| 槟城当入口（深圳→槟城 … 新加坡→深圳） | ≈ ¥745 + ¥1,248 = **¥1,993** |
| 吉隆坡门户 + 国内段接驳（深圳→吉隆坡 + KUL→PEN + 槟城→香港） | ≈ ¥573 + ¥189 + ¥591 = **¥1,353** |

**建议：不要把马来西亚的门户机场设成槟城，而要把槟城放在行程最后当出境口岸。** 路线「深圳/香港 → 新加坡 → 马六甲 → 吉隆坡 → 槟城 → 香港」自南向北一走到底不回头，机票只比原方案多约 ¥20。

已知风险：
1. PEN→HKG 的 UO769 是 00:50→04:45 红眼，落地香港凌晨，机场快线头班约 05:50。
2. 用「吉隆坡→槟城→再往南」会构成回头路；要省 KUL→PEN 那 ¥189，只能买同一张 SZX→KUL→PEN 联程票（行李直挂、不入境吉隆坡）。
