### 主线（当前采用）

新加坡 3 天 → 新山 1–2 天 → 马六甲 1–2 天 → 吉隆坡 2–3 天 → 槟城 2 天（出境），共 10–11 天，自南向北不回头。反向亦可，但按 11 月最低价方向 A 更便宜（≈¥1,591 vs ≈¥1,662）。

四段陆路：新加坡→新山 CW 巴士 S$2.60–4.80／新山→马六甲巴士 RM20–35（213 km，3–3.5h）／马六甲→吉隆坡巴士 RM12–25（2–2.5h）／吉隆坡→槟城 ETS 火车 3h35m–4h20m（每天 7 班）。


### 数据口径

- 所有机票、景点评分/票价、巴士票价为 **2026-10-11** 当日从公开平台页面实际抓取的快照；
- 机票价格**保留来源页面自身币种**（US$ / HK$ / SGD / MYR / CNY），未做汇率换算；
- 查不到的字段一律写「未查到」，不做推测；
- 图片全部来自 Wikimedia Commons 自由许可内容，作者与协议在页面「数据来源」章节逐张列出。
